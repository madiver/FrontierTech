# Prompts

Reusable prompts for creating project documents and guiding coding agents.

## Available Prompts

- [New Project Scaffold](new-project-scaffold.md) - sets up a new project folder with git, agent instructions, .gitignore, README, tool checks, initial commit, and optional GitHub repository creation with a chosen license.
- [Create Agent Instructions File](create-agent-instructions-file.md) - asks an agent to create `AGENTS.md` for Codex or `CLAUDE.md` for Claude Code with generic engineering policies.
