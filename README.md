# Frontier Tech

Generic documents, prompts, checklists, and lightweight workflows for software projects.

This repository is intended for public-facing material that other builders can reuse in their own projects. Keep artifacts practical, project-neutral, and easy to copy into a new codebase.

## Contents

- `prompts/` - reusable prompts for coding agents, project setup, reviews, and planning workflows.
- `tools/` - common development tools with descriptions and official install links.

## Artifact Guidelines

- Prefer concise, reusable documents over project-specific instructions.
- Avoid private company, client, repository, credential, or infrastructure details.
- Include enough context that an artifact works when copied into a different project.
- Keep examples generic unless a technology-specific artifact is intentionally being created.
- Use plain Markdown wherever possible.
